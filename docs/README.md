# Cafe Admin 설계 문서

무료 클라우드 기반의 여러 카페와 사용자 N:N 서비스를 위한 MVP 설계 문서입니다. 현재 로컬 HTML 앱에서 전환하기 위한 계획이며 구현 완료를 의미하지 않습니다.

| 문서 | 내용 |
| --- | --- |
| [PRD](PRD.md) | 제품 목표, 역할과 권한, 무료 클라우드 구성, 범위와 출시 기준 |
| [작업 계획서](WORK_PLAN.md) | 16개 작업, 선행 관계, 일정, PR 분할, 검증 체크리스트 |
| [정보 구조 IA](IA.md) | 화면 ID, 메뉴 구조, 제안 경로, 역할별 접근과 화면 상태 |
| [아키텍처 설계서](ARCHITECTURE.md) | 시스템 구성, 데이터 모델, API·인증, 동시성, 자료 이전, 배포·복구 |
| [사용자 플로우차트](USER_FLOWS.md) | 로그인·초대·카페 전환·저장·충돌·자료 이전 등 Mermaid 흐름 |

읽는 순서는 PRD → IA → 사용자 플로우 → 아키텍처 → 작업 계획서를 권장합니다. 실제 구현은 작업 계획서의 단계 순서로 진행합니다.

역할 정책과 제품 범위는 PRD를 기준으로 합니다. IA·플로우의 화면 경로와 추가 정책은 설계 제안이며, 구현 전에 작업 계획서 W02에서 정리합니다. 요구사항 변경 시 관련 문서와 검증 기준을 함께 갱신합니다.
