# Cafe Admin

설치 없이 사용하는 로컬 카페 운영 장부입니다. 매출·구매·비용·근무·급여·재고를 기록하고 기간별 손익을 확인합니다.

## 다운로드 및 실행

[최신 배포본 다운로드](https://github.com/a01094864335-cell/cafe-admin/releases/latest)

1. 릴리스의 `Cafe-Admin.zip`을 다운로드합니다.
2. 압축을 풀고 `index.html`을 Chrome 또는 Edge로 엽니다.
3. 설정에서 매장 이름을 지정하고 기록을 시작합니다.

서버·설치·인터넷 연결 없이 실행됩니다. 라이트·다크 모드를 지원합니다.
배포본에는 실제 매장의 장부나 개인정보가 없으며 빈 데이터로 시작합니다.

## 저장과 여러 사용자

각 사용자가 내려받아 자신의 PC와 브라우저에서 독립적으로 사용합니다.
여러 사람의 동시 편집·공유 서버·자동 동기화 기능은 없습니다.
기록은 HTML 파일이 아니라 브라우저 저장소에 저장됩니다.
시크릿 창을 피하고 같은 브라우저·프로필·파일 위치에서 사용하세요.
브라우저 데이터 삭제, 파일 이동, 업데이트 전에 **설정 → 백업 내려받기**로 JSON을 보관하세요.
다른 PC에서는 **설정 → 백업 복원**으로 기록을 옮깁니다. 복원은 현재 장부를 교체합니다.

## 시트로 내려받기

조회 기간을 적용한 뒤 **시트로 내려받기**를 누르면 `.xlsx` 파일을 저장합니다.
매출·기타수익·구매·근무·주휴·월 기타수당·월별 매출 대조·재고·손익을 별도 탭으로 담습니다.
검색·분류·화면 페이지와 무관하게 선택 기간의 기록을 모두 포함하며, 재고는 현재 전체 수량입니다. 월별 매출 대조는 조회 기간이 걸치는 월 전체를 기준으로 합니다.
Excel 또는 Google Sheets에서 열 수 있고 인터넷 없이 내려받을 수 있습니다. 금액은 숫자, 미입력 값은 빈칸으로 저장하며 급여 미확정 상태도 표시합니다.
시트는 현재 계산값을 담은 열람용이며, 장부 복원에는 기존 JSON 백업을 사용하세요.

## 급여 계산 범위

현재 파트타이머 1명과 2026–2027년 설정을 다루는 운영용 프로토타입입니다.
근무 설정에서 시급·입사일·약정시간·주휴요일을 먼저 입력하세요. 시급 기본값은 제공하지 않습니다.
출퇴근과 실제 무급휴게를 기준으로 기본급을 계산하고, 주휴는 확인 상태에 따라 반영합니다.
연장·야간·휴일 가산, 세금·보험·퇴직금은 자동 계산하지 않습니다.
잔액은 기록된 항목의 단순 합계이며 확정 회계이익이 아닙니다.

## 구성

- `index.html`: 스타일·스크립트가 포함된 단일 실행 파일
- `README.md`: 사용 안내

UI는 shadcn/ui 대시보드 구성을 참고한 독립 HTML 구현입니다.
